Sheet language quick reference

Every kind of line a CivilKit Calcs sheet takes, its inputs, and the functions, constants, operators and units of the engine, on one page that prints well. Use Print and choose Save as PDF to keep a copy. The full account is in the user guide.

Functions

Arguments are separated by commas in a sheet (the engine's semicolon also works inside brackets). A function written with a unit-bearing argument returns its result with the right unit.

Units

Write a unit after a number (300 MPa, 9.81 m/s², 5 kN*m). The engine combines and checks them, so a unit error is a mistake caught. Prefixes (k, M, G, m, µ, n and the rest of the SI set) apply to the metric units. Convert a result with -> unit, show a ratio as a percentage with -> %, and show a result in SI base units with -> base. Point at a unit for its meaning.
