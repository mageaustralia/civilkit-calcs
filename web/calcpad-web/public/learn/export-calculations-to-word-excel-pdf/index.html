Export calculations to Word, Excel and PDF

A calculation is only finished when someone else can read it. CivilKit Calcs turns a calculated sheet into a Word document with real equations, an Excel workbook with the workings and native charts, a PDF through the print dialog, or a standalone HTML page. Every file is written in the browser, from the same calculated report you see on screen, and it works offline.

Where the exports are

The Document tab has buttons for Print PDF, Word, Excel and Export. The File menu has Print PDF, Export and Export Excel. The Export dialog lists the views you can export (Report, Preview, Input form, Unwrapped), each with its own Save PDF, Save Word and Save HTML buttons, and a list of the plots that downloads each one as an image, or all of them as a ZIP. Report is the usual choice: it applies the values entered in an input form.

Try it

Change the inputs and the results recalculate in your browser. Embed it on your own site.

Open the sheet in Calcs if the live sheet does not show.

An example to try

The beam bending sample is a short check with units:

# Beam bending check

A simply supported beam under a uniform load. The units are real, so the moment
**comes out in kN·m** because the engine tracks them.

## Inputs
L: 6 m | span
w: 12 kN/m | design uniform load
fy: 300 MPa | yield strength of the steel
Ze: 1.23e6 mm³ | effective section modulus
phi: 0.9 | capacity factor

## Design action
Mstar: w * L^2 / 8 -> kN*m | maximum bending moment at mid-span

## Capacity
Ms: fy * Ze -> kN*m | section moment capacity
phiMs: phi * Ms -> kN*m | design capacity

## Check
utilisation: Mstar / phiMs
if utilisation <= 1: "OK: the beam passes in bending." else: "Fails: increase the section."

The report shows a moment of 54 kN·m, a design capacity of 332.1 kN·m and a utilisation of 0.163, with the formulas, the substituted numbers and an OK line. Open it with the button on this page and export it to each format to compare.

Word

  • Equations are real Word equations (Office Math): fractions, subscripts, sums, matrices and units, editable in the document.
  • Headings, paragraphs, lists, links and tables keep their form.
  • Plots and other drawings are pictures, stored as PNG with the SVG kept beside it.
  • A formula typeset with LaTeX in a sheet appears as its TeX source in italics, not as a Word equation.
  • An interactive chart cannot be carried, and a paragraph stands in its place. A matplotlib-style figure from a Python block is carried as a picture.

The Word file has been checked in LibreOffice, not in Microsoft Word.

Excel

The workbook mirrors the calculation. The Report sheet holds the report in document order, with every equation as a row: description, name, expression, expression with the numbers put in, value and unit. A Variables sheet lists every variable with its last value and unit, each vector or matrix gets a sheet of its own, an Inputs sheet holds the values from input fields, and a Plot data sheet holds the points of every plot. Each plot becomes a native XY chart on the Report sheet, pointing at the plot data, so you can edit it.

The cells hold calculated values with the expressions as text, not live formulas, so changing a cell does not recalculate the rest. The workbook opens in LibreOffice and a Python reader; it has not been tried in Microsoft Excel.

PDF and HTML

Print PDF opens the browser's print dialog on the report: choose Save as PDF. The page size, orientation and margins come from the PDF settings. A page break line starts a new page, in the PDF and in Word; the + menu between blocks and the Document tab both insert one.

Save HTML writes a standalone page with the report, its styles, fonts and pictures. An exported input form is static: it shows the controls, but nothing recalculates behind them.

Questions

Are the Word equations editable?

Yes. They are native Word equations, not pictures. A formula typed in LaTeX in a sheet is the exception: it appears as its TeX source.

Does the Excel workbook recalculate?

No. The cells hold calculated values with the expressions as text. Change the inputs in the sheet and export again.

Is my calculation uploaded to make the files?

No. The Word and Excel writers run in the page and work offline once they have loaded.

Which view should I export?

Report, usually. It applies the values entered in an input form.
