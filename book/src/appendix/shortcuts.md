# Appendix: keyboard shortcuts

<!-- description: Keyboard shortcuts for saving, calculating, finding, renaming and editing in CivilKit Calcs, with Cmd in place of Ctrl on a Mac. -->

On a Mac use Cmd where this page says Ctrl. The Resources tab has a **Shortcuts** button that lists
the main ones in the output panel.

| Shortcut | Action |
| --- | --- |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+O | Open (the desktop app; a browser keeps its own Open command) |
| Ctrl+Alt+X | Calculate. F5 does the same in the desktop app; in a browser F5 reloads the page. |
| Ctrl+Z, Ctrl+Shift+Z | Undo, redo |
| Ctrl+F | Find in the editor |
| Ctrl+Shift+B | Show or hide the sidebar (the desktop app; in a browser use Resources > Sidebar) |
| Alt+Z | Wrap long lines |
| Ctrl+Shift+E | Convert the selected expression to a formula line (see [Editing](../editing.md)) |
| Shift+Alt+F | Format Document (tidy a sheet) |
| F12 | Go to the definition of the name under the cursor |
| Shift+F12 | Find references |
| F2 | Rename the variable, function or macro under the cursor everywhere in the worksheet (see [Editing](../editing.md)) |
| Ctrl+; | Variable palette: search every variable and function with its value. Enter inserts the name, Alt+Enter goes to its definition |
| Tab | Accept the highlighted completion (Enter makes a new line) |
| Ctrl+Space | Open the completion list by hand |
| Ctrl+B, Ctrl+I, Ctrl+U | Bold, italic, underline in text lines of a Calcpad worksheet |
| Enter, Ctrl+Enter | Apply an in-place edit (Ctrl+Enter for prose) |
| Esc | Cancel an in-place edit, or close a dialog |
| Enter, Shift+Enter | In the Symbolic dialog: run, new line |

**Keys the browser keeps.** In a browser the keys that browsers use themselves are left to the
browser, so that the page never takes them: Ctrl+L, D, R, N, P, T, W, Q and J, Ctrl+0 to 9
(tab switching and zoom), Ctrl+plus and Ctrl+minus, and Ctrl+Shift+V. Menu commands such as New
sheet are on the ribbon. Save (Ctrl+S) is the page's own.

**On a phone** there are no shortcuts; see [Editing](../editing.md).
